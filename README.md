# Les amis de 10

Appli pour iPad : apprendre les compléments à 10 (7 + 3 = 10) avec le cadre de 10.

**Ouvrir l’application : https://ludo1104-rp.github.io/amis-de-10/**

- Apprendre : les 11 amis de 10, avec un cadre de 10 qui se remplit.
- Trouve l’ami : 7 + ? = 10.
- Les paires : touche les 2 nombres qui font 10.
- Le labyrinthe : passe seulement par les calculs qui font 10.
- Mes calculs difficiles et Mes progrès (enregistrés sur l’appareil).
- 3 défis, style Couleurs ou Simple, 3 tailles de texte. Tout est dans `index.html`, sans connexion.

Version 1.1 — Application produite par IA. Des erreurs peuvent survenir.
